\# AutoScaleLab - Docker Swarm



\## Objectif



Cette partie du projet permet de déployer et gérer l'application AutoScaleLab avec Docker Swarm.



Docker Swarm est utilisé pour :

\- déployer le service ;

\- gérer les replicas ;

\- effectuer le Scale Out ;

\- effectuer le Scale In ;

\- maintenir le service disponible.



\## Prérequis



\- Docker Desktop

\- Docker Engine

\- Docker Swarm

\- Git Bash ou WSL pour les scripts `.sh`



\## Initialiser Docker Swarm



```bash

bash init-swarm.sh
